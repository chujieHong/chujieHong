# 知序 · 多模型与知识库助手

基于自研多模型调用层，构建支持来源引用的 RAG 文档问答系统。项目包括模型调用工具与知识库问答两部分，目前为个人开发与实验项目。

## 源码与命名

- **公开模型调用层：[m1 / LLM Toolkit](https://github.com/chujieHong/m1)**。知序是项目的展示名称，链接指向的仓库仍名为 m1，未重命名仓库。
- **知识库问答部分：m2，本地开发中，尚未在本介绍页提供公开源码入口。** m1 仓库不包含全部 RAG 实现。

## 多模型调用层

统一接入 MiniMax、DeepSeek，提供 CLI 与 Web 入口，支持流式输出、Prompt 模板、异常重试、SQLite 对话历史及调用用量统计。采用可扩展 Provider 结构，区分同步与异步调用，并复用客户端连接。

## RAG 文档问答

已实现文档读取与切片、Chroma 本地向量检索、基于检索材料的回答与来源编号引用，提供文档上传、索引、搜索和问答接口。

围绕固定开发题集，开展 BM25、向量检索、RRF 融合及重排序对比实验，使用 Recall、MRR 等指标分析检索结果。实验功能与在线问答链路分别迭代，不表示全部实验方案已默认集成；不将开发题集结果作为独立测试集或生产效果承诺。
