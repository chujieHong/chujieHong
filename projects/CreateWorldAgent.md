# CreateWorldAgent

> 从故事到可试玩的 2D 像素剧情游戏。

CreateWorldAgent 是一个本地 AI 游戏制作工作台，探索将小说、剧本、字幕及结构化故事材料改编为可独立运行的 2D 像素剧情游戏。

## 项目功能

- **故事改编**：根据故事材料与制作要求，开展剧情改编和玩法设计。
- **游戏制作**：结合 AI 生成像素素材、实现游戏并执行检查与测试。
- **试玩与修改**：查看制作记录、试玩候选版本，并通过自然语言提出修改。
- **版本管理与导出**：管理制作版本，导出可通过 HTTP 服务独立运行的静态 HTML5 游戏。

## 当前状态

项目处于可运行开发阶段，仍在持续完善制作流程与生成质量；不同故事的成品质量和稳定性需要进一步验证。
