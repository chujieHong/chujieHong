# CreateWorldAgent

> 让故事成为可玩的世界，让创意在共创中持续生长。

**面向普通用户的本地 AI 游戏工作台 · 开源共创与二创生态**

CreateWorldAgent 面向普通用户，将小说、剧本等故事材料改编为 **2D 像素剧情游戏**。用户以故事和创意为起点，通过自然语言参与制作、试玩与修改，逐步将想象转化为可以体验、迭代和分享的游戏作品。

项目同时探索一个连接创作者、开发者与玩家的游戏开发生态，以 **开源共创、二次创作与多 IP 交融** 为方向，让作品拥有持续拓展的空间。

## 从故事到游戏

把故事变成游戏，需要让人物、场景与情节转化为玩家可以参与的体验。CreateWorldAgent 将这些环节整合到本地工作台中，降低从故事构想到游戏原型的创作门槛。

| 创作环节 | 工作台能力 |
| :--- | :--- |
| 故事改编 | 基于小说、剧本等材料，开展剧情改编、场景组织与玩法设计。 |
| 游戏制作 | 结合 AI 完成像素素材制作、游戏实现与检查测试。 |
| 试玩迭代 | 查看制作记录，试玩候选版本，通过自然语言提出修改。 |
| 版本与导出 | 管理制作版本，导出可通过 HTTP 服务独立运行的静态 HTML5 游戏。 |

## 从个人创作到生态共创

CreateWorldAgent 的长期愿景，是让游戏创作从个人的一次尝试，延伸为更多人可以参与的持续共创。

- **开源共创** — 探索开放协作的工具与内容建设，让开发经验、创作方法与可复用成果在社区中积累。
- **二次创作** — 围绕已有故事与作品，探索新的视角、剧情分支和玩法表达，让创作者接续拓展游戏世界。
- **多 IP 交融** — 探索不同角色、世界设定与叙事体系之间的联动，构建更丰富的跨世界游戏体验。

**普通用户表达创意，创作者拓展故事，开发者完善工具，玩家通过体验反馈参与作品成长。** 这是项目希望逐步建立的共创循环。
